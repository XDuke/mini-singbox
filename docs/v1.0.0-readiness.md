# v1.0.0 release readiness

The independent `mini-singbox v1.0.0` release is authorized only from the
reviewed root commit of `XDuke/mini-singbox`.

| Gate | Result | Evidence |
|---|---|---|
| Strict local schema and three-protocol core | Pass | unit/race/fuzz/vet and live clients |
| Official core only | Pass | sing-box v1.13.16, no module replacement |
| No control plane or prohibited feature path | Pass | source, dependency, and binary scans |
| No compilation on small targets | Pass | immutable CI/release assets only |
| amd64/arm64 static builds | Pass | CI and tag workflow |
| Non-root/hardened runtime | Pass | systemd/OpenRC and scratch container checks |
| Shared NAT delivery | Pass | distinct public/listen ports and refreshed QR links |
| 128 MiB runtime | Pass | live load, no swap/OOM/drop; see validation record |
| Runtime stability | Pass | maintainer sign-off plus zero restart/error live evidence |
| Vulnerability scan | Pass | govulncheck release gate |
| Signed supply chain | Pass before publication | minisign, SHA-256, SBOM, provenance |
| Rollback and uninstall | Pass | guarded backup/rollback and purge separation |

See [validation.md](validation.md) for sanitized measurements and
[release.md](release.md) for immutable publication requirements.

## Product boundary

Aggregation subscriptions, Web panels, multiple users, remote configuration,
automatic update daemons, traffic statistics, management APIs, rate limiting,
TUN/WireGuard, arbitrary routing, and additional protocol families are not part
of v1.0.0.
